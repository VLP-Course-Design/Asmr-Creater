# 样例图片(前端 Demo 用)

把 4 张样例图放进本目录,文件名必须与下表一致。放进来后网页会自动显示真实图片;**文件缺失时页面会自动回退到虚线占位框**,不会报错。

| 文件名        | 需要什么图                                                                 | 建议来源                      |
| ------------- | -------------------------------------------------------------------------- | ----------------------------- |
| `bedroom.jpg` | 夜晚卧室,暗调冷色;窗边在下雨,左侧有一只猫在睡觉                          | `img_dataset/Train/42.jpg` 或自选 |
| `cafe.jpg`    | 午后咖啡馆,暖光;画面有热气腾腾的杯子、笔记本电脑、聊天的人                | 自选                          |
| `forest.jpg`  | 清晨森林,明亮暖调;有鸟、有溪流                                            | 自选                          |
| `misty.jpg`   | 雾山黎明,冷调、朦胧;**画面里没有明显可发声物体**(用来演示纯氛围底噪场景) | 自选                          |

## 运行方式

点击页面中的样例名称后，浏览器会读取对应图片并调用后端 `/infer`，实时生成视觉记录、检测框和播放计划。样例不再使用 `index.html` 内手写的框或锚点；后端不可用或图片读取失败时，页面会显示错误，不会伪造检测结果。

## 尺寸建议

- 横向构图,建议 1200×800 左右,jpg 格式。
- 页面用 `object-fit:cover` 填充预览区，检测框按后端返回的归一化坐标定位；替换图片后不需要同步修改前端框坐标。

## 版权

样例图请使用自有图片、CC0 或数据集内图片,并在报告中注明来源。
