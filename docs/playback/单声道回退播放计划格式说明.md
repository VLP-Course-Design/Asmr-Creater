# ASMR 单声道回退播放计划格式说明

**计划版本：** `2.0-mono`  
**输出声道：** 1  
**渲染方式：** 中央单声道  
**适用输入：** 双耳空间质量门控未通过，或播放端不支持 HRTF

## 1. 目标

当视觉锚点的深度信息不完整、不确定性过高、区域深度分散过大，或播放端不支持 HRTF 时，本格式提供确定、安全且不依赖空间推断的播放计划。

单声道回退不是错误状态。它保留场景环境声、局部触发音、情绪修饰、随机调度和助眠安全规则，只移除左右、远近、仰角、HRTF、空间运动和环绕扩散参数。

## 2. 回退触发条件

空间门控默认配置：

```json
{
  "uncertainty_threshold": 0.35,
  "max_region_spread": 0.50,
  "minimum_spatial_candidate_count": 1,
  "require_depth_for_all_candidates": true,
  "comparison": "strict_less_than"
}
```

满足以下任意一项时必须生成本计划：

1. `spatial_candidates` 为空。
2. 任一候选缺少完整的 `depth_hint`。
3. 任一候选 `depth_hint.type != relative_monocular`。
4. 任一候选 `depth_hint.class == unknown`。
5. 任一候选 `uncertainty >= uncertainty_threshold`；默认即 `uncertainty >= 0.35`。
6. 任一候选 `region_spread > 0.50`。
7. 框、深度、素材或空间配置校验失败。
8. 播放端不支持 HRTF、用户选择单声道，或输出设备策略要求单声道。

被声音映射和安全过滤淘汰的视觉锚点不属于 `spatial_candidates`，不参与门控。

## 3. 顶层结构

```json
{
  "schema_version": "2.0-mono",
  "plan_id": "plan_example_coastal_sunset_0001_mono",
  "source_record_id": "example_coastal_sunset_0001",
  "seed": 18432,
  "duration_s": 1800,
  "render": {},
  "fallback": {},
  "layers": {
    "ambient": [],
    "noise_bed": null,
    "foreground": []
  },
  "master": {},
  "decision_trace": {}
}
```

### 3.1 顶层字段

| 字段 | 类型 | 必填 | 限制 |
|---|---|---:|---|
| `schema_version` | string | 是 | 固定为 `2.0-mono` |
| `plan_id` | string | 是 | 计划集合内唯一 |
| `source_record_id` | string | 是 | 对应视觉记录 `id` |
| `seed` | integer | 是 | 控制素材变体和触发调度复现 |
| `duration_s` | number \| null | 是 | 大于 0；`null` 表示持续播放 |
| `render` | object | 是 | 单声道输出契约 |
| `fallback` | object | 是 | 记录为何未使用双耳模式 |
| `layers` | object | 是 | 环境、底噪和前景层 |
| `master` | object | 是 | 单声道总线和安全限制 |
| `decision_trace` | object | 否 | 调试和审计信息 |

## 4. `render` 格式

```json
{
  "mode": "mono_center",
  "output_channels": 1,
  "spatialization": "disabled",
  "downmix_policy": "equal_power",
  "channel_interpretation": "speakers"
}
```

- `mode` 固定为 `mono_center`。
- `output_channels` 固定为 1。
- 计划中不得出现 `pan`、`azimuth_deg`、`elevation_deg`、`virtual_distance_m`、HRTF、空间混响或运动轨迹。
- 立体声源素材进入单声道总线时，必须使用等功率降混策略，并在离线测试中检查相位抵消。
- 如果某立体声素材降混后明显失真，应在 Manifest 中提供经过审核的单声道派生素材，并引用其独立 `asset_id`。

## 5. `fallback` 格式

```json
{
  "from": "2.0-binaural",
  "policy_version": "spatial_gate_v1",
  "result": "failed",
  "uncertainty_threshold": 0.35,
  "comparison": "strict_less_than",
  "max_region_spread": 0.50,
  "candidate_count": 2,
  "evaluated_anchor_indices": [0, 1],
  "failure_reasons": [
    {
      "code": "DEPTH_UNCERTAINTY_NOT_BELOW_THRESHOLD",
      "source_anchor_index": 1,
      "observed": 0.47,
      "required": "< 0.35"
    }
  ]
}
```

### 5.1 失败代码

| 代码 | 含义 |
|---|---|
| `NO_SPATIAL_CANDIDATES` | 没有会参与播放的空间锚点 |
| `DEPTH_HINT_MISSING` | 至少一个候选缺少深度提示 |
| `DEPTH_TYPE_UNSUPPORTED` | 深度类型不受支持 |
| `DEPTH_CLASS_UNKNOWN` | 相对距离等级未知 |
| `DEPTH_UNCERTAINTY_NOT_BELOW_THRESHOLD` | `uncertainty` 大于或等于临界值 |
| `DEPTH_REGION_SPREAD_TOO_HIGH` | 框内深度分散超过上限 |
| `INVALID_SPATIAL_INPUT` | 框、深度或相关字段校验失败 |
| `HRTF_UNAVAILABLE` | 播放端不支持所需 HRTF 能力 |
| `MONO_REQUESTED` | 用户或设备策略明确要求单声道 |

`failure_reasons` 必须至少包含一项，并可记录多个原因。不得只写自由文本原因。

## 6. 环境层

环境层最多两个，结构如下：

```json
{
  "layer_id": "ambient_primary",
  "role": "primary",
  "sound_id": "ocean_waves",
  "asset_id": "amb_ocean_waves_mono_02",
  "mode": "loop",
  "gain_db": -18.0,
  "lowpass_hz": 12000,
  "fade_in_ms": 2500,
  "fade_out_ms": 3000,
  "loop_crossfade_ms": 2500,
  "channel_mode": "mono"
}
```

| 字段 | 规则 |
|---|---|
| `layer_id` | 计划内唯一 |
| `role` | `primary` 或 `secondary` |
| `sound_id` | 稳定声音语义 |
| `asset_id` | 必须在 Manifest 中存在 |
| `mode` | 环境层固定为 `loop` |
| `gain_db` | dB；次层应低于主层 |
| `lowpass_hz` | 大于 0 且不超过素材 Nyquist 频率 |
| `fade_in_ms` / `fade_out_ms` | 非负整数 |
| `loop_crossfade_ms` | 正整数，且与 Manifest 已验证循环信息一致 |
| `channel_mode` | 固定为 `mono` |

环境声选择仍由 `scene_type`、兼容的次场景和安全回退规则决定，与空间模式无关。

## 7. 底噪层

底噪最多一个，可以为 `null`：

```json
{
  "layer_id": "noise_bed",
  "role": "noise_bed",
  "sound_id": "pink_noise",
  "mode": "generated_loop",
  "gain_db": -36.0,
  "lowpass_hz": 9000,
  "fade_in_ms": 3000,
  "fade_out_ms": 3000,
  "channel_mode": "mono"
}
```

真实环境声充分时必须为 `null`。单声道回退本身不得成为自动添加底噪的理由。

## 8. 前景层

前景层仍来自视觉锚点，但不使用其位置、大小和深度：

```json
{
  "layer_id": "trigger_bird_0",
  "role": "trigger",
  "sound_id": "bird_chirp",
  "asset_pool": [
    "trg_bird_chirp_mono_01",
    "trg_bird_chirp_mono_02",
    "trg_bird_chirp_mono_03"
  ],
  "mode": "random_trigger",
  "gain_db": -30.0,
  "lowpass_hz": 11000,
  "schedule": {
    "min_interval_s": 35,
    "max_interval_s": 90,
    "probability": 0.35,
    "selection": "shuffle_no_repeat",
    "max_simultaneous": 1
  },
  "source_anchor_index": 0,
  "channel_mode": "mono"
}
```

- 前景层最多两个。
- `source_anchor_index` 保留，用于追溯声音来源，但不得用于空间定位。
- `schedule` 必须满足 `0 < min_interval_s < max_interval_s`、`0 <= probability <= 1`。
- `selection` 固定为 `shuffle_no_repeat`，防止机械重复。
- `max_simultaneous` 助眠默认 1。
- 检测置信度和深度不确定性不得直接控制音量。

## 9. 总线

```json
{
  "output_channels": 1,
  "gain_db": -2.0,
  "limiter_threshold_db": -1.0,
  "fade_in_ms": 2500,
  "fade_out_ms": 3000,
  "max_foreground_simultaneous": 1
}
```

强制限制：

1. 环境层最多两个，前景层最多两个，底噪最多一个。
2. 所有层均输出到唯一中央单声道总线。
3. 不得包含任何随时间变化的空间参数。
4. 所有素材均须在 Manifest 中解析；循环层必须具有已验证的循环信息。
5. 总线必须保留安全余量，不得削波或出现突然增益变化。
6. 禁止尖叫、警报、突然鸣笛、爆裂声和清晰可辨识对话。

## 11. 验收测试

- [ ] 任一参与锚点 `uncertainty >= 0.35` 时输出本计划。
- [ ] 无空间候选或播放端无 HRTF 能力时输出本计划。
- [ ] 计划中不存在 `pan`、方位、距离、HRTF、空间混响或运动字段。
- [ ] 所有声音最终合并为一个中央单声道总线。
- [ ] 立体声素材降混经过相位和响度检查。
- [ ] 相同输入、配置、Manifest 和 seed 产生相同素材与调度结果。
- [ ] 回退只移除空间效果，不改变场景声音选择与助眠安全逻辑。
- [ ] 单声道试听无削波、明显相位抵消、突发增益或机械重复。
