# 8/7 demo 全链路测试报告（问题清单）

**结论**：上传 → VLM + YOLO → 合并 JSON → schema 校验 → 前端渲染，链路能跑通（7 张图实测全过）。以下为发现的问题，按严重度排序。

**状态复核（2026-08-13）**：问题 1 已解决（8/8 commit 2c4927b）；问题 7/10 为说明项；其余 7 条未解决（待认领）；8/8 补记：问题 11（素材库三层断链）、问题 12（EXIF 旋转）均未解决。

## 高

### 1. 前端检测框错位 ✅ 已解决（8/8 commit 2c4927b）
- **问题**：hero 背景 `background-size:cover`（裁切）+ `transform:scale(1.04)`（放大），检测框按整图百分比定位 → 框对不上物体。
- **责任人**：UI（`src/ui/web/index.html`）。
- **建议**：在「自定义图片」区用不裁切预览出框；或 hero 改 contain + 去 scale。

### 2. VLM 静默回退默认值 ❌ 未解决（待认领）
- **问题**：Ollama 未启动/VLM 失败时，/infer 仍返回 200 + 默认氛围 + 空 VLM 实体，前端无提示。
- **责任人**：后端（`src/ui/app.py`）。
- **建议**：失败时响应加 `vlm_ok:false` 或非 200；前端明确提示；录屏前确认 Ollama 在跑。

## 中

### 3. 溯源字段泄露本机路径（隐私） ❌ 未解决（待认领）
- `image.path` 填服务器临时绝对路径（含 Windows 用户名），下载/分享 Scene Contract 会泄露。责任人：后端。建议：改 `f.filename` 或省略。

### 4. 非图片文件上传返回 200 + 假数据 ❌ 未解决（待认领）
- 传 txt 冒充图片返回 200 + 默认氛围，不报错。责任人：后端。建议：非法图片返回 400/415。

### 5. 实体名命中素材库仅约 10%（v5 全量实测 10.2%） ❌ 未解决（待认领）
- VLM 输出自由词（people/birds/trees），trigger_map 只认单数精确 key。责任人：音频层（归一化）+ 素材线（别名/扩充）。

### 11. ⚠️ 素材库三层断链（demo 无真实音效） ❌ 未解决（素材线+UI）
- **问题**：1) sounds/ 下真实音频文件 0 个（目录全为 .gitkeep 占位）；2) 前端 Web Audio 用合成音（VOICE 频率表），不读素材库；3) 音频层 pyo 未接入 demo。
- **责任人**：素材线（补素材）+ UI（按 trigger_map 播 wav）。

### 12. ⚠️ EXIF 旋转未处理（手机照片框上下错位） ❌ 未解决（视觉层预处理）

- **责任人**：视觉层预处理（src/vision/preprocess.py）。
