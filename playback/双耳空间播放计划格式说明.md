# ASMR 双耳空间播放计划格式说明

**计划版本：** `2.0-binaural`  
**输出声道：** 2（耳机双声道）  
**渲染方式：** HRTF 双耳渲染  
**适用输入：** 单张图片视觉记录 schema 2.2 及以上

## 1. 目标

本格式用于在视觉锚点的相对深度质量满足门控条件时，将锚点的水平位置、垂直位置、相对深度和实体大小转换为稳定、克制且可复现的耳机空间音效。

本计划生成的是“基于单张图片构造的虚拟前方声场”，不是对真实三维空间的测量。实体锚点默认位于听者前方；侧后方包围感只能由环境声床和混响扩散产生。

本文中的“必须”“不得”“应”“可以”分别对应强制要求、禁止要求、推荐要求和可选能力。

## 2. 双耳模式准入门控

### 2.1 参与门控的锚点

先对 `trigger_anchors` 执行声音映射、置信度门控、助眠安全过滤、去重和层数预算。只有最终可能进入播放计划的锚点组成 `spatial_candidates`。

不能映射到声音、被安全规则排除或预算淘汰的视觉锚点不参与空间质量门控，避免无关检测结果导致整份计划错误降级。

### 2.2 默认门控参数

```json
{
  "uncertainty_threshold": 0.35,
  "max_region_spread": 0.50,
  "minimum_spatial_candidate_count": 1,
  "require_depth_for_all_candidates": true,
  "comparison": "strict_less_than"
}
```

`uncertainty_threshold` 必须来自版本化配置，默认值为 `0.35`。临界比较必须使用严格小于：`uncertainty < 0.35`；等于临界值视为不通过。

### 2.3 准入判定

仅当以下条件全部成立时生成本计划：

1. `spatial_candidates.length >= 1`；空集合不得因“全部满足”而进入双耳模式。
2. 每个候选均具有完整的 `depth_hint`。
3. 每个 `depth_hint.type` 均为 `relative_monocular`。
4. 每个 `depth_hint.class` 均不是 `unknown`。
5. 每个候选均满足 `uncertainty < uncertainty_threshold`。
6. 每个候选均满足 `region_spread <= max_region_spread`。
7. 所有框坐标、深度值和素材引用均通过校验。
8. 播放端声明支持本计划指定的 HRTF 渲染能力。

等价伪代码：

```text
use_binaural = spatial_candidates.length >= minimum_spatial_candidate_count
  AND renderer_supports_hrtf
  AND every(candidate has complete depth_hint)
  AND every(depth_hint.type == "relative_monocular")
  AND every(depth_hint.class != "unknown")
  AND every(depth_hint.uncertainty < uncertainty_threshold)
  AND every(depth_hint.region_spread <= max_region_spread)

if not use_binaural:
    generate plan_version = "2.0-mono"
```

门控结果必须冻结在计划中。前端不得自行改变判定。

## 3. 顶层结构

```json
{
  "schema_version": "2.0-binaural",
  "plan_id": "plan_example_coastal_sunset_0001_binaural",
  "source_record_id": "example_coastal_sunset_0001",
  "seed": 18432,
  "duration_s": 1800,
  "render": {},
  "quality_gate": {},
  "layers": {
    "ambient": [],
    "noise_bed": null,
    "foreground": []
  },
  "master": {},
  "decision_trace": {}
}
```

### 3.1 顶层字段

| 字段 | 类型 | 必填 | 限制 |
|---|---|---:|---|
| `schema_version` | string | 是 | 固定为 `2.0-binaural` |
| `plan_id` | string | 是 | 计划集合内唯一 |
| `source_record_id` | string | 是 | 对应视觉记录 `id` |
| `seed` | integer | 是 | 相同输入、配置、素材库和 seed 必须得到相同计划 |
| `duration_s` | number \| null | 是 | 大于 0；`null` 表示持续播放 |
| `render` | object | 是 | 声道、HRTF 和坐标系契约 |
| `quality_gate` | object | 是 | 记录空间模式准入证据 |
| `layers` | object | 是 | 环境、底噪和前景层 |
| `master` | object | 是 | 总线、安全限幅和淡入淡出 |
| `decision_trace` | object | 否 | 调试和审计信息 |

## 4. `render` 格式

```json
{
  "mode": "binaural_hrtf",
  "output_channels": 2,
  "headphone_required": true,
  "listener_pose": {
    "position": [0.0, 0.0, 0.0],
    "forward": [0.0, 0.0, -1.0],
    "up": [0.0, 1.0, 0.0]
  },
  "coordinate_system": "right_handed_y_up_listener_relative",
  "hrtf_profile": "renderer_default_v1",
  "distance_model": "inverse",
  "reference_distance_m": 1.0,
  "max_distance_m": 15.0,
  "rolloff_factor": 0.55
}
```

| 字段 | 规则 |
|---|---|
| `mode` | 固定为 `binaural_hrtf` |
| `output_channels` | 固定为 2 |
| `headphone_required` | 固定为 `true`；扬声器播放不保证空间效果 |
| `listener_pose` | 以听者为原点，计划期间保持静止 |
| `hrtf_profile` | 必须是播放端可解析的版本化配置 |
| `reference_distance_m` | 大于 0；默认 1.0 |
| `max_distance_m` | 大于 `reference_distance_m`；建议不超过 15 |
| `rolloff_factor` | 建议范围 0～1；助眠默认 0.55，避免过强距离衰减 |

## 5. `quality_gate` 格式

```json
{
  "result": "passed",
  "policy_version": "spatial_gate_v1",
  "uncertainty_threshold": 0.35,
  "comparison": "strict_less_than",
  "max_region_spread": 0.50,
  "candidate_count": 1,
  "evaluated_anchor_indices": [0],
  "maximum_observed_uncertainty": 0.18,
  "fallback_plan_version": "2.0-mono"
}
```

`result` 在本格式中必须为 `passed`。若为其他值，计划非法并必须重新生成为单声道版本。

## 6. 环境层与底噪

### 6.1 环境层

环境层最多两个，来自 `scene_type` 和兼容的次场景。原生立体声素材可以作为宽环境床播放，但不得绑定单一实体框。

```json
{
  "layer_id": "ambient_primary",
  "role": "primary",
  "sound_id": "ocean_waves",
  "asset_id": "amb_ocean_waves_02",
  "mode": "loop",
  "gain_db": -18.0,
  "lowpass_hz": 12000,
  "fade_in_ms": 2500,
  "fade_out_ms": 3000,
  "loop_crossfade_ms": 2500,
  "spatial": {
    "render_mode": "diffuse_stereo_bed",
    "azimuth_width_deg": 100.0,
    "rear_diffusion": 0.18,
    "head_locked": true
  }
}
```

- `azimuth_width_deg` 范围 0～180。
- `rear_diffusion` 范围 0～0.35；它是氛围扩散，不表示可见实体位于身后。
- 环境床不得使用视觉框计算极端声像。

### 6.2 底噪

底噪最多一个且可以为 `null`。使用时保持中央扩散，不参与实体定位；真实环境声充分时必须为 `null`。

## 7. 前景空间层

每个前景层必须引用一个通过门控的视觉锚点：

```json
{
  "layer_id": "trigger_bird_0",
  "role": "trigger",
  "sound_id": "bird_chirp",
  "asset_pool": [
    "trg_bird_chirp_01",
    "trg_bird_chirp_02",
    "trg_bird_chirp_03"
  ],
  "mode": "random_trigger",
  "gain_db": -30.0,
  "lowpass_hz": 11000,
  "schedule": {
    "min_interval_s": 35,
    "max_interval_s": 90,
    "probability": 0.35,
    "selection": "shuffle_no_repeat",
    "max_simultaneous": 1
  },
  "source_anchor_index": 0,
  "spatial": {
    "render_mode": "point_source_hrtf",
    "base_position": {
      "azimuth_deg": 41.4,
      "elevation_deg": 8.1,
      "virtual_distance_m": 9.52
    },
    "visual_evidence": {
      "center_x": 0.845,
      "center_y": 0.23,
      "bbox_area": 0.002,
      "relative_depth": 0.82,
      "depth_uncertainty": 0.18,
      "size_prior_used": true,
      "size_prior_version": "visual_size_priors_v1"
    },
    "source_width": 0.08,
    "distance_gain_db": -4.2,
    "distance_lowpass_hz": 9000,
    "reverb_send": 0.26,
    "motion": {
      "mode": "seeded_micro_motion",
      "seed_offset": 101,
      "azimuth_range_deg": 3.0,
      "elevation_range_deg": 1.0,
      "distance_range_ratio": 0.04,
      "period_s": 42.0,
      "smoothing_ms": 1500
    }
  }
}
```

### 7.1 静态位置映射

```text
center_x = (x_min + x_max) / 2
center_y = (y_min + y_max) / 2
bbox_area = (x_max - x_min) × (y_max - y_min)

azimuth_deg = clamp((center_x - 0.5) × 120, -60, 60)
elevation_deg = clamp((0.5 - center_y) × 30, -15, 15)
depth_distance_m = 1 + 11 × relative_depth^1.3
```

`elevation_deg` 是弱视觉提示，范围必须压缩在 ±15° 内。音频测试表明上下定位不稳定时，应进一步压缩或固定为 0°。

### 7.2 实体大小的使用

实体大小不得替代深度模型。只有存在版本化的实体尺寸先验时，才允许用框面积做小幅距离修正：

```text
linear_size = sqrt(bbox_area)
size_ratio = linear_size / typical_linear_size(anchor_id)
size_distance_multiplier = clamp(1 / sqrt(size_ratio), 0.80, 1.20)
virtual_distance_m = clamp(
  depth_distance_m × size_distance_multiplier,
  1.0,
  15.0
)
```

- `typical_linear_size(anchor_id)` 必须来自版本化配置。
- 没有该实体的先验时，`size_prior_used=false`，距离只使用相对深度。
- 无尺寸先验时，框宽可以温和影响 `source_width`，但不得改变真实距离语义。
- 特写、裁切、镜头焦距和透视会影响框大小，因此修正倍数必须限制在 0.80～1.20。

### 7.3 动感规则

单张图片不提供真实运动轨迹。`seeded_micro_motion` 是音频表现策略，不是视觉事实，必须满足：

| 参数 | 允许范围 | 建议默认 |
|---|---:|---:|
| `azimuth_range_deg` | 0～5° | 2～3° |
| `elevation_range_deg` | 0～2° | 0.5～1° |
| `distance_range_ratio` | 0～0.08 | 0.03～0.05 |
| `period_s` | 18～90 s | 30～60 s |
| `smoothing_ms` | 800～5000 ms | 1500 ms |

- 位移必须连续平滑，不得瞬移、绕头旋转或快速左右横跳。
- 微动不得使前方实体进入听者后方。
- 固定物体如键盘、杯子、时钟默认关闭运动，或只允许不超过 1° 的极轻微扩散变化。
- 鸟、飞行物、树叶等可使用较高但仍受限的微动。
- 所有运动必须由 `seed + seed_offset` 确定，保证测试可复现。

### 7.4 距离听觉参数

距离感必须联合使用增益、低通和混响，且保持助眠安全：

```text
distance_gain_db = clamp(-6 × log10(virtual_distance_m), -7, 0)
distance_lowpass_hz = clamp(16000 - 700 × virtual_distance_m, 6500, 16000)
reverb_send = clamp(0.08 + 0.025 × virtual_distance_m, 0.08, 0.38)
```

这些参数描述虚拟音频舞台，不表示现实物理测量。素材本身已经明显遥远或带混响时，应通过素材标签降低二次处理强度。

## 8. 总线与全局安全限制

```json
{
  "output_channels": 2,
  "gain_db": -2.0,
  "limiter_threshold_db": -1.0,
  "fade_in_ms": 2500,
  "fade_out_ms": 3000,
  "max_foreground_simultaneous": 1,
  "spatial_parameter_smoothing_ms": 800
}
```

强制限制：

1. 环境层最多两个，前景层最多两个，底噪最多一个。
2. `virtual_distance_m` 范围 1～15。
3. 实体基础方位限制为前方 `[-60°, 60°]`；微动后仍不得超过 `[-65°, 65°]`。
4. HRTF 参数变化必须平滑，禁止突然位置跳变。
5. 所有素材必须能在 Manifest 中解析；循环层必须已验证无缝循环。
6. 总输出不得削波；前景事件默认最多同时播放一个。
7. 不得播放尖叫、警报、突然鸣笛、爆裂声或清晰可辨识对话。

## 10. 验收测试

- [ ] 候选集合非空，且所有候选 `uncertainty < 0.35`。
- [ ] 任一候选缺少深度、深度为 `unknown` 或达到临界值时，系统输出单声道计划。
- [ ] 相同输入、配置、Manifest 和 seed 产生相同位置、运动及调度。
- [ ] 框水平位置正确对应左右方位，EXIF 方向无误。
- [ ] 框大小只在存在实体尺寸先验时修正距离。
- [ ] 所有实体基础位置及微动保持在前方安全角度内。
- [ ] 固定实体无明显漂移，活动实体只有缓慢微动。
- [ ] 耳机试听无贴耳、瞬移、绕头、削波或高频刺激。
